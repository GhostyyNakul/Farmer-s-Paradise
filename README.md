# Farmer's Paradise — Cinematic Agricultural Landing Page

> *"Where better decisions grow better farms."*

A luxury, cinematic, highly interactive digital experience for modern precision agriculture. Designed with an editorial aesthetic, deep natural color tones, smooth GSAP ScrollTrigger flight animations, and an interactive scroll-scrubbed environmental story.

## 🌿 Key Features & Storytelling Flow

1. **Hero — Cinematic Farm Atmosphere**:
   - Fullscreen procedural morning landscape with sunrise, drifting mist, swaying wheat stalks, mountain depth, and gold sunbeams.
   - Editorial headline typography and scroll progress hint.

2. **Scroll-Driven Video / Canvas Journey**:
   - Scrollwheel scrubbing through 7 visual phases (Sunrise horizon -> Field approach -> Leaf micro-structure -> Soil strata -> AI matrix -> Canopy expansion -> Aerial view).
   - HTML5 Video fallback ready.

3. **"Every Field Tells a Story" (Section 2)**:
   - Spatial nodes pinned to environmental coordinates: SOIL (ground), CROP (plants), WEATHER (sky) with animated connecting data vectors.

4. **AI Crop Assistant (Section 3)**:
   - Interactive leaf spectral scanner with animated scanning laser.
   - Specialized agricultural decision tree for diagnostic inquiry ("My tomato leaves are turning yellow").

5. **Underground Soil Ecosystem (Section 4)**:
   - Deep dive through earth layers: Surface -> Root zone -> Humus strata -> Microorganisms.
   - Environmental readouts for pH, Nitrogen, Phosphorus, Potassium, Moisture, and Soil Organic Carbon.

6. **Soil Testing Journey (Section 5)**:
   - Horizontal diagnostic pipeline: Sample Collection -> Lab Spectrometry -> AI Analysis -> Recipe Recommendation.

7. **Crop Recommendation Matrix (Section 6)**:
   - Algorithmic match formula (Soil + Weather + Location = Crop Match).
   - Highlighting Golden Durum Wheat (96%), Yellow Mustard (91%), Heirloom Tomato (88%).

8. **Nearby Soil Testing Labs Map (Section 7)**:
   - Stylized dark vector geographic map with animated pulse vectors connecting the farm plot to nearby accredited laboratories.

9. **Final Paradise Transformation (Section 8)**:
   - Thriving sunlit paradise transition with emotional statement reveals and CTA.

## 🛠️ Tech Stack

- **React 18** + **TypeScript**
- **Vite 6**
- **GSAP 3** & **ScrollTrigger**
- **Lenis** Smooth Scroll
- **Tailwind CSS 3**
- **Lucide Icons**

## 🚀 Local Development

```bash
# Run local development server
npm run dev

# Build production bundle

```
